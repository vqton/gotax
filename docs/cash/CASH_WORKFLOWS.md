# Cash Module — Workflows

**Circular:** 99/2025/TT-BTC | **Forms:** 01-TT, 02-TT, S07-DN, S04a-DNN, 08a-TT

---

## 1. Cash Receipt Workflow

```
┌─────────────────────────────────────────────────────────────┐
│ 1. CREATE                                 Draft             │
│    - Kế toán lập Phiếu thu                                  │
│    - Nhập: ngày, số tiền, người nộp, lý do, TK đối ứng     │
│    - Đính kèm chứng từ gốc                                  │
└─────────────────────┬───────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. SUBMIT                                 Submitted         │
│    - Kiểm tra: bắt buộc nhập, cân đối Nợ/Có                │
│    - Chuyển lên Kế toán trưởng                              │
└─────────────────────┬───────────────────────────────────────┘
          ┌───────────┴───────────┐
          ▼                       ▼
┌──────────────────┐  ┌──────────────────┐
│ 3a. APPROVE      │  │ 3b. REJECT      │
│ - KT trưởng ký   │  │ - Ghi rõ lý do  │
│ - Nếu > hạn mức  │  │ - Trả về Draft  │
│   → Giám đốc ký  │  │                  │
└────────┬─────────┘  └────────┬─────────┘
         ▼                     ▼
┌──────────────────┐  ┌──────────────────┐
│ 4. POST          │  │ Back to Draft    │
│ - Ghi sổ quỹ     │  │ (sửa + submit    │
│ - Ghi sổ kế toán │  │  lại)            │
│ - Cập nhật số dư  │  └──────────────────┘
│ In Phiếu thu     │
└──────────────────┘

Status Flow: Draft → Submitted → Approved → Posted
             Draft → Submitted → Rejected → Draft
```

## 3. Cash Inventory Workflow

```
┌─────────────────────────────────────────────────────────────┐
│ 1. INITIATE                                                 │
│    - Lập Ban kiểm kê (KT trưởng + Thủ quỹ)                │
│    - Thông báo thời điểm kiểm kê                           │
└─────────────────────┬───────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────┐
│ 2. PREPARE                                                  │
│    - Thủ quỹ ghi sổ tất cả phiếu thu/chi đến thời điểm     │
│    - Tính số tồn quỹ trên sổ                               │
└─────────────────────┬───────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────┐
│ 3. COUNT                                                    │
│    - Kiểm đếm từng loại tiền theo mệnh giá                 │
│    - Ghi vào Biên bản kiểm kê (Mẫu 08a-TT)                 │
└─────────────────────┬───────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────┐
│ 4. COMPARE                                                  │
│    - Sổ sách vs Thực tế                                     │
│    - Tính chênh lệch                                        │
└─────────────────────┬───────────────────────────────────────┘
          ┌───────────┴───────────┐
          ▼                       ▼
┌──────────────────┐  ┌──────────────────┐
│ 4a. KHỚP         │  │ 4b. CHÊNH LỆCH  │
│ = 0 difference   │  │ ≠ 0 difference   │
│ - Ký biên bản    │  │ - Xác định N/V  │
│ - Lưu hồ sơ      │  │ - Xử lý thừa/   │
└──────────────────┘  │   thiếu          │
                      │ - Hạch toán bổ   │
                      │   sung           │
                      │ - Ký biên bản    │
                      └──────────────────┘
```

## 4. Petty Cash Workflow

```
┌─────────────────────────────────────────────────────────────┐
│ ESTABLISH FUND                                              │
│ - Lập quỹ tạm ứng: người nhận, số tiền, mục đích          │
│ - KT trưởng duyệt                                           │
│ - Xuất quỹ: Chi tạm ứng (Nợ 141/Có 111)                   │
│ - Thủ quỹ ghi sổ                                           │
└─────────────────────┬───────────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────────┐
│ SETTLEMENT                                                  │
│ - Người nhận nộp chứng từ chi                              │
│ - KT kiểm tra: hóa đơn hợp lệ?                             │
│ - Nếu chi > tạm ứng → chi bổ sung                          │
│ - Nếu chi < tạm ứng → thu hồi                             │
│ - KT trưởng duyệt                                          │
│ - Hạch toán: Nợ TK CP/Có 141                             │
└─────────────────────────┬───────────────────────────────────┘
                          ▼
┌─────────────────────────────────────────────────────────────┐
│ CLOSE FUND                                                  │
│ - Khi kết thúc: thu hồi toàn bộ tồn quỹ                   │
│ - Nợ 111/Có 141                                            │
│ - Đóng quỹ                                                  │
└─────────────────────────────────────────────────────────────┘
```

## 5. Bank Transfer Workflow

```
RÚT TIỀN NGÂN HÀNG VỀ NHẬP QUỸ
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ Lập giấy │   │ Rút tiền │   │ Nhập quỹ│   │ Hạch toán│
│ đề nghị  │ → │ tại NH   │ → │ tiền mặt│ → │ Nợ 111   │
│ rút tiền │   │          │   │          │   │ Có 112   │
└──────────┘   └──────────┘   └──────────┘   └──────────┘

GỬI TIỀN VÀO NGÂN HÀNG
┌──────────┐   ┌──────────┐   ┌──────────┐   ┌──────────┐
│ Lập đề  │   │ Xuất quỹ│   │ Gửi NH   │   │ Hạch toán│
│ nghị gửi│ → │ tiền mặt│ → │          │ → │ Nợ 112   │
│         │   │          │   │          │   │ Có 111   │
└──────────┘   └──────────┘   └──────────┘   └──────────┘
```

## 6. End-of-Day Cashier Workflow

```
┌─────────────────────────────────────────────────────────────┐
│ DAILY CASHIER ROUTINE                                       │
│ 1. Kiểm tra số dư đầu ngày                                 │
│ 2. Ghi nhận phiếu thu trong ngày                           │
│ 3. Ghi nhận phiếu chi trong ngày                           │
│ 4. Kiểm kê quỹ cuối ngày (đối chiếu sổ vs thực tế)       │
│ 5. Ký xác nhận sổ quỹ                                      │
│ 6. Đối chiếu với kế toán tiền mặt                          │
│ 7. Chuyển chứng từ cho kế toán                             │
└─────────────────────────────────────────────────────────────┘
```
